# Digital Sathi — ڈیجیٹل ساتھی

ایک جدید، تیز رفتار اور محفوظ ویب پورٹل اور ایپ اسٹور برائے تصدیق شدہ اینڈرائڈ ایپس (APKs)، مفید آن لائن ٹولز، پی ڈی ایف لائبریری اور آئی ٹی سروسز۔

---

## 🌟 خصوصیات و فیچرز (Features Overview)

1. **مکمل ریسپانسو و جدید ڈیزائن (Modern Responsive UI):**
   - نیوی بلیو (`#070F2B`, `#0B192C`)، پیور وائٹ (`#FFFFFF`) اور الیکٹرک سیان (`#00E5FF`) رنگوں کا امتزاج۔
   - ڈیسک ٹاپ، لیپ ٹاپ، ٹیبلٹ اور موبائل پر 100% ہم آہنگ۔
   - موبائل اسکرین کے لیے نیچے فکسڈ نیویگیشن بار (Bottom Navigation Bar)۔

2. **دو لسانی انتخاب (Urdu & English Bilingual Support):**
   - اردو نستعلیق رسم الخط (RTL) اور انگلش (LTR) کے درمیان ایک کلک سے فوری تبدیلی۔
   - تمام صفحات، فارمز، پیغامات اور بٹنز پر خودکار ترجمہ۔

3. **ڈارک اور لائٹ موڈ (Dark & Light Mode Engine):**
   - ہائی ٹیک ڈارک تھیم اور دن کے وقت کے لیے کلین لائٹ تھیم۔

4. **ایپ اسٹور و کیٹیگریز (App Store & Categories):**
   - کیٹیگریز: Finance & Khata، Islamic، Education، Tools & Utilities، Productivity، Media & Editing۔
   - لائیو انسٹنٹ سرچ، فلٹرز اور ترتیب (مقبول، زیادہ ریٹنگ، نیا ورژن، فائل سائز)۔
   - ایپ کی تفصیلی معلومات: اسکرین شاٹس گیلری، ورژن، سائز، SHA-256 چیک سم، کم از کم اینڈرائڈ، اور تبدیلیوں کی فہرست (Changelog)۔

5. **محفوظ و تصدیق شدہ ڈاؤن لوڈ سسٹم (Safe Download Verification):**
   - 3 سیکنڈ کا خودکار سیکیورٹی و وائرس اسکین اینیمیشن۔
   - گوگل ڈرائیو و فاسٹ سی ڈی این سرور کے تصدیق شدہ براہِ راست لنکس۔
   - خراب یا ناقابلِ رسائی لنک کی صورت میں صارف کے لیے رپورٹ کرنے کی سہولت۔

6. **مفید انٹرایکٹو آن لائن ٹولز (Interactive Tools Suite):**
   - **کھاتہ و منافع کیلکولیٹر:** آمدن، لاگت، اخراجات، ادھار اور خالص منافع کا فوری حساب اور پرنٹ ایبل رسید۔
   - **مستند شرعی زکوٰۃ کیلکولیٹر:** سونے، چاندی، کیش اور مالِ تجارت کے نصاب پر 2.5 فیصد کا حساب۔
   - **کیو آر کوڈ جنریٹر:** واٹس ایپ، ویب سائٹ، وائی فائی اور ٹیکسٹ کا ایچ ڈی کیو آر۔
   - **رومن اردو سے نستعلیق کنورٹر:** رومن اردو ٹائپ کریں اور نستعلیق تحریر حاصل کریں۔
   - **ڈیٹا اسٹوریج و یونٹ کنورٹر:** MB, GB, TB اور پیمائش کی فوری تبدیلی۔

7. **پی ڈی ایف و دستاویزات لائبریری (PDF & Useful Files):**
   - دکان و کاروبار کی کھاتہ بک ایکسل/پی ڈی ایف۔
   - فری لانسنگ گائیڈ بک 2026۔
   - مسنون دعائیں و کمپیوٹر شارٹ کٹس۔

8. **پیشہ ورانہ سروسز (IT Services):**
   - موبائل ایپ ڈویلپمنٹ، ویب سائٹ ڈیزائننگ، اور گرافک ڈیزائننگ کے لیے کوٹیشن بکنگ فارم۔

9. **محفوظ ایڈمن پینل (Secure Admin CMS Dashboard):**
   - ایڈمن یو آر ایل: `http://localhost:3000#admin`
   - یوزر نیم: `admin`
   - پاس ورڈ: `Admin@DigitalSathi2026`
   - سرور پر پاس ورڈ کی `bcryptjs` انکرپشن اور `JWT` ٹوکن سیشن مینجمنٹ۔
   - ایپس، کیٹیگریز، فائلز، کسٹمر پیغامات، سروس آرڈرز اور ترتیبات کا مکمل انتظام (CRUD)۔

## 🚀 چلانے کا طریقہ (How to Run Locally)

```bash
# 1. پراجیکٹ ڈائریکٹری میں جائیں
cd "e:\Digital Sathi"

# 2. سرور اسٹارٹ کریں
node server.js
```

ویب سائٹ براؤزر میں کھولیں:
- **ویب سائٹ:** `http://localhost:3000`
- **ایڈمن پینل:** `http://localhost:3000#admin`

---

## 🛠️ ٹیکنالوجی اسٹیک (Technology Stack)

- **بیک اینڈ:** Node.js, Express 5, Node 24 Native SQLite (`DatabaseSync`), JWT, Bcrypt.js, CORS
- **ڈیٹابیس:** `digital_sathi.db` (SQLite فائل، زیرو کنفیگریشن)
- **فرنٹ اینڈ:** HTML5 Semantic, Modern Vanilla CSS3 (Custom Design System, Glassmorphism, CSS Grid & Flexbox), Vanilla JavaScript ES6+
- **فونٹس:** Google Fonts (Outfit, Inter, Noto Nastaliq Urdu, Noto Sans Arabic)
- **آئیکنز:** FontAwesome 6 Pro CDN

---

## 🔒 سیکیورٹی و پروڈکشن ڈپلائمنٹ (Deployment Guidelines)

پروڈکشن سرور (VPS / Ubuntu / cPanel / Railway / Render) پر چلاتے وقت درج ذیل انوائرنمنٹ متغیرات سیٹ کریں:

```env
PORT=3000
JWT_SECRET=your_super_secret_jwt_random_key_here_2026
```

ایڈمن لاگ ان کر کے اپنا پاس ورڈ ایڈمن پینل کے "پاس ورڈ تبدیل کریں" سیکشن سے فوراً اپ ڈیٹ کر سکتے ہیں۔
